# OjiTopology — Blender Quad Remesher Add-on (v3)

選択したオブジェクトを **四角形ポリゴン主体のきれいなエッジフロー** へ自動
リトポロジー（quad remesh）する Blender アドオン。**目標頂点数を指定** して
ワンクリックで実行できる。ZBrush の ZRemesher のように、マテリアル境界・
頂点グループ・シャープエッジで「ポリグループ」を指定し、エッジフローを誘導
できる。

## バージョン履歴と設計の反省

- **v1**: Blender ネイティブの `quadriflow_remesh` をラップ（中身が見えない
  ブラックボックス）。
- **v2**: Instant Meshes の position field を実装し、頂点を格子へ収束させて
  からクラスタリング・格子抽出で quad を作ろうとした。しかし各エッジの整数
  オフセットを独立に丸める簡易抽出では大域的に整合した格子にならず、**穴
  だらけ・三角形だらけ**になった。さらに純 Python のループは**ハイポリの
  スカルプトで停止して空メッシュ化（メッシュが消える）**した。
- **v3（現行）**: クラスタリングと格子抽出を撤廃し、**堅牢性を最優先**した
  パイプラインに作り直した。穴やメッシュ消失が起きず、必ず有効な quad 主体
  メッシュになる。

## できること

- 目標頂点数を指定したクリーンな quad 主体リトポロジー
- N パネル（サイドバー）の UI から大きなボタン一発で実行
- ポリグループ指定によるエッジフロー誘導（自動検出 or 頂点グループ）
- シャープ／境界／マテリアル境界の保持、スムーズシェード、X/Y/Z 対称
- **ハイポリのスカルプトでも安全**（自動デシメーションで規模を抑える）
- 元サーフェスへの Shrinkwrap でディテール保持

## インストール

1. Blender を開く
2. `Edit > Preferences > Add-ons`
3. `Install...`（4.2 以降は `Install from Disk...`）から `ojitopology.py` を選択
4. 一覧の **OjiTopology Quad Remesher** にチェックを入れて有効化

> Blender 3.0 以降で動作。Blender 同梱の numpy を使用する。

## 使い方

1. メッシュオブジェクトを選択（オブジェクトモード）
2. 3D ビューポートで `N` キー → **OjiTopology** タブ
3. **目標頂点数** を入力
4. 必要なら **ポリグループ / 特徴線** でエッジフローを誘導:
   - 「角度で自動検出」: 鋭いエッジ（角など）を自動でガイドにする
   - 「頂点グループを使用」: ウェイトペイント等で作った頂点グループの境界
     （自分で指定するポリグループ）に沿ってエッジフローを揃える
5. **Quad Remesh** ボタンを押す
6. 完了後、ヘッダに `頂点数 / 面数 / quad率` が表示される

## アルゴリズム（パイプライン）

ZRemesher のような「ポリグループに沿った quad メッシュ」を目標に、Python で
独自実装している（Blender ネイティブの quadriflow には依存しない）。

1. **入力取得（ハイポリ安全化）** — 入力が大きすぎる場合は C++ の Decimate
   モディファイアで安全な面数まで落としてから処理する。これにより数十万〜
   数百万ポリのスカルプトでも停止・メッシュ消失を起こさない。

2. **特徴線（ポリグループ境界）検出** — シャープマーク／面の角度／開いた
   境界／マテリアル境界／頂点グループの輪郭を特徴線として検出する。

3. **等方リメッシュ** — 表面積 `A` と目標頂点数 `N` から目標辺長
   `L ≈ √(A / N)` を求め、辺の分割／収縮で整った（ほぼ均一な）三角土台を作る
   （Botsch & Kobbelt 2004 の isotropic remeshing）。特徴エッジは保護する。

4. **Orientation field（4-RoSy cross field）** — Jakob et al. *“Instant
   Field-Aligned Meshes”* (SIGGRAPH Asia 2015) に基づき、各頂点に「エッジが
   流れるべき方向」を持たせる。Taubin の曲率テンソル法 (ICCV 1995) で主曲率
   方向から初期化し、隣接頂点との 90°対称マッチングによる局所平滑化を反復
   する。**特徴線上の頂点はその線の接線方向に固定**し、ポリグループ境界に
   沿ってエッジフローを揃える（ZRemesher の Polygroups と同じ役割）。

5. **field 誘導 quad マッチング** — 整った三角網の隣接三角形ペアについて、
   共有辺を溶解してできる四角形が cross field にどれだけ沿うか・正方性・
   平面性をスコア化し、スコアの高い順に貪欲に選んで共有辺を溶解する。
   特徴エッジは溶解せず残す。任意の三角網では約 80% が quad になり、残りは
   特異点付近の三角形／多角形として残る（これは ZRemesher 等でも避けられない）。

6. **流れの整え** — 特徴線・境界を固定したサーフェス拘束スムージングで
   エッジループを直線的に整える。

7. **元サーフェスへ投影** — Shrinkwrap で元メッシュ表面へスナップし、
   スカルプトのディテールを保持する。

8. **対称仕上げ** — X/Y/Z 対称指定時は Bisect + Mirror で厳密な対称形にする。

## 既知の限界（正直な注意）

- **純 Python の速度**: cross field 平滑化は概ね 250 頂点/秒程度。作業頂点数を
  最大 15,000 に自動制限している（約 1 分）。それ以上の高密度な出力は出せない。
- **quad 率**: 約 80%。完全 all-quad ではなく quad 主体（quad-dominant）。
  完全な all-quad や、ZRemesher のような途切れのない長いエッジループの再現は
  純 Python の範囲では困難（本来はエッジ整数変数の大域最適化が必要）。
- **実機未検証**: bmesh 操作（等方リメッシュ／quad 溶解／Shrinkwrap／Mirror）は
  この開発環境では Blender が無く実行できないため、数値コア（cross field・
  quad マッチングのスコアリング）のみ合成データでオフライン検証済み。実機での
  見た目確認はこれから。問題があればフィードバックを。
